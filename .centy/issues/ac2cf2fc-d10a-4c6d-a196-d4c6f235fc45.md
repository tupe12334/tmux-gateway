# Strip debug symbols from release binary

The release binary is currently **21 MB**. Stripping debug symbols can significantly reduce the binary size.

## Suggested change

Add to `Cargo.toml`:

````toml
[profile.release]
strip = true
````

This removes debug info and symbol tables from the final binary.

## Expected impact

Typically reduces binary size by 30-60%.
