# Add tmux documentation links to schema types, commands, and domains

## Problem

The project’s schemas (OpenAPI, GraphQL, Protocol Buffers) and domain types expose tmux concepts — sessions, windows, panes, buffers, options, layouts, environment variables — but none of them link to the official tmux documentation. Developers consuming these APIs must separately search the tmux man page to understand the underlying semantics of each domain object, command, or option value.

## Proposed solution

Add a `docs_url` or `externalDocs` reference pointing to the relevant section of the tmux manual for every domain entity, command, and enumeration value across all three schema formats:

### Domain types (`tmux-gateway-core`)

Add `/// [tmux docs](https://man.openbsd.org/tmux#...)` doc-comments and `#[schema(external_docs(...))]` annotations (utoipa) to:

* **TmuxSession** — link to CLIENTS AND SESSIONS
* **TmuxWindow** — link to WINDOWS AND PANES
* **TmuxPane** — link to WINDOWS AND PANES
* **TmuxOption** / **OptionScope** — link to OPTIONS
* **TmuxBuffer** — link to BUFFERS
* **TmuxEnvVar** — link to ENVIRONMENT
* **PaneLayout** — link to select-layout
* **SplitDirection** — link to split-window
* **ResizeDirection** — link to resize-pane

### Commands / operations

Link each command operation to its corresponding tmux command section:

* `list_sessions` → `list-sessions`
* `create_session` → `new-session`
* `kill_session` → `kill-session`
* `list_windows` → `list-windows`
* `new_window` → `new-window`
* `send_keys` → `send-keys`
* `capture_pane` → `capture-pane`
* `split_window` → `split-window`
* `resize_pane` → `resize-pane`
* `select_layout` → `select-layout`
* `swap_panes` → `swap-pane`
* `get_option` / `set_option` → `show-options` / `set-option`
* `list_buffers` / `get_buffer` / `set_buffer` → buffer commands
* `show_environment` / `set_environment` → `show-environment` / `set-environment`
* …and all remaining operations

### Schema files

* **OpenAPI** (`schemas/openapi.json`): Add `externalDocs` at the schema and operation level
* **GraphQL** (`schemas/schema.graphql`): Add doc-string descriptions with links
* **Protobuf** (`schemas/tmux_gateway.proto`): Add doc comments with links

### Base URL

All links should point to the canonical OpenBSD man page: `https://man.openbsd.org/tmux`
with fragment anchors to the specific command (e.g., `https://man.openbsd.org/tmux#new-session`).

## Acceptance criteria

* [ ] Every domain struct/enum in `tmux-gateway-core` has a doc-comment linking to the relevant tmux man-page section
* [ ] OpenAPI spec includes `externalDocs` for each schema and operation
* [ ] GraphQL schema descriptions include tmux doc links
* [ ] Protobuf comments include tmux doc links
* [ ] Links are verified to resolve to the correct section
