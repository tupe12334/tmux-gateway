## Problem

The project has no `examples/` directory. Users can’t quickly see how to use the core library with `cargo run --example`.

## Proposed change

Create `examples/basic_session.rs` demonstrating the core session lifecycle using `tmux-gateway-core`:

* Create a session
* List sessions
* Capture pane output
* Kill session
