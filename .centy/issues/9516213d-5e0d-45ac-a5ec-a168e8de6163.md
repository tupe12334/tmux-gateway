# Set codegen-units = 1 for release builds

The release binary is currently **21 MB**. By default, Rust splits crates into multiple codegen units for parallel compilation. Setting `codegen-units = 1` allows the compiler to perform better optimizations across the entire crate.

## Suggested change

Add to `Cargo.toml`:

````toml
[profile.release]
codegen-units = 1
````

## Trade-offs

Increases compile time but produces a smaller and potentially faster binary by giving LLVM more optimization opportunities.
