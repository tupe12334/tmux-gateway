# Enable LTO for release builds

The release binary is currently **21 MB**. Enabling Link-Time Optimization (LTO) allows the linker to perform whole-program optimization, removing unused code across crate boundaries.

## Suggested change

Add to `Cargo.toml`:

````toml
[profile.release]
lto = true
````

## Expected impact

Reduces binary size and can also improve runtime performance, at the cost of longer compile times.
