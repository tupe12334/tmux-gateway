# Use opt-level z for size-optimized release builds

The release binary is currently **21 MB**. Using `opt-level = "z"` tells the compiler to optimize aggressively for binary size rather than speed.

## Suggested change

Add to `Cargo.toml`:

````toml
[profile.release]
opt-level = "z"
````

## Trade-offs

This may slightly reduce runtime performance compared to the default `opt-level = 3`, but can meaningfully shrink the binary.
